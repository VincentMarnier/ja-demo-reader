# M5: demo player controls, external HUD and settings

**Status:** Implemented on `master`.
**Scope:** Follow camera, free camera, persistent player settings, external
scoreboard/scores/timer, and hidden in-game scoreboard/scores/timer/radar.

## Features

### Follow player

The scoreboard panel lists the clients that are actual players (spectators are
filtered out). **Follow** switches the demo camera to a third-person view behind
that player. **Demo camera** returns to the recorded camera.

The cgame override is applied after the normal demo camera calculation and
tracks the selected entity each frame. If the target disappears or becomes a
spectator, the override clears itself.

### Free camera

**Free cam** switches to a free-flying camera. The initial pose is taken from
the current demo view. While the demo is playing:

| Action | Default key |
|---|---|
| Move forward | `W` |
| Move back | `S` |
| Strafe left | `A` |
| Strafe right | `D` |
| Move up | `Space` |
| Move down | `Ctrl` |
| Look left / right | `←` / `→` |
| Look up / down | `↑` / `↓` |

All ten bindings can be changed in Settings. Movement is sent to the cgame over
the wasm bridge; it is not tied to the game's input bindings. The first-person
view weapon is suppressed while an external camera is active.

### External HUD

The in-game scoreboard, mini scores, timer, radar and bottom score line are
suppressed:

| Cvar | Value |
|---|---|
| `cg_externalHud` | `1` |
| `cg_drawScores` | `0` |
| `cg_drawTimer` | `0` |
| `cg_drawRadar` | `0` |

The React UI supplies:

- A **scoreboard panel** beside the demo, with names, scores, ping and Follow
  buttons. The setting can hide the panel.
- A **score strip** at the top center. Team games show Red/Blue scores; duel and
  FFA demos show the top two players. The setting can hide it.
- A **timer** between the score blocks. The setting can hide it.
- The right-side in-game score line is also suppressed by `cg_externalHud`.

The in-game Tab scoreboard is disabled in cgame (`CG_DrawScoreboard` and the
`+scores` handlers return early when `cg_externalHud` is set).

### Settings

Settings are stored in `localStorage` under
`jka-demo-player.settings.v1` and applied on load:

- `cgFov` — default **97**; range 60–130. Applied through `JKA_SetCvar`.
- Show scoreboard panel — default on.
- Show scores — default on.
- Show timer — default on.
- Free-camera key bindings — ten rebindable actions, with reset.

The FOV is also set as a startup cvar so the first frame uses 97 before the
settings panel is opened.

## Bridge additions

| Function | Purpose |
|---|---|
| `JKA_SetCvar` / `JKA_GetCvar` | Apply/read `cg_fov` and other cvars |
| `JKA_ScoreboardJson` | Player names, scores, ping, team and team scores |
| `JKA_FollowClient` | Select/clear the followed player |
| `JKA_EnableFreeCam` | Enable free cam and return its initial pose |
| `JKA_SetFreeCamPose` | Update free-cam origin/angles |
| `JKA_DisableFreeCam` | Return to the normal camera |

The cgame-side implementation lives in `cg_view.c`; `cg_externalHud`,
`cg_fov` and the scoreboard/score-line guards are in `cg_xcvar.h`,
`cg_consolecmds.c` and `cg_draw.c` (all applied by
`engine/patches/0004-emscripten-rend2.patch`).

## Persistence and playback state

- The score strip/scoreboard poll the cgame once per second while a demo is
  playing, paused or ended.
- Starting, restarting and stopping a demo clears follow/free-cam state.
- Settings persist across reloads; the engine still needs its assets selected
  after a reload.

## Limitations

- Follow and free cam take effect while the demo is running; a paused engine
  only redraws after Resume.
- Free cam has no collision detection.
- Settings are per browser profile and only store the player-side options, not
  engine assets or map choices.
- The external HUD is demo-player specific; the `rd-vanilla` branch retains the
  original in-game HUD behavior.
